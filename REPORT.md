Engineering Justification

To fulfill the requirement for a multi-agent system that avoids LLM hallucinations and grounds its outputs in authoritative sources, I designed a cyclic evaluation workflow using LangGraph. Unlike linear frameworks (e.g., CrewAI), LangGraph’s state graph architecture allows for a robust pedagogical critique loop. The workflow binds a custom local file-reading tool to the Researcher Agent, injecting the specific CEFR guidelines into the context window. If the Critic Agent detects that the Generator produced content exceeding the target CEFR level, it routes the workflow back for revision. This ensures the curriculum is deterministic and pedagogically accurate before it ever reaches the user.

To manage the context window and structurally guarantee that the parsing logic remains unbreakable, I utilized LangChain's .with_structured_output() integrated with strict Pydantic models. By defining separate root schemas (VocabularyCurriculum and GrammarCurriculum) and employing @model_validator decorators, the system enforces data cleanliness and de-duplication at the generation layer. This dual-schema approach ensures the output is strictly typed, preventing schema drift and making the data instantly ready for downstream analytics or database insertion.
